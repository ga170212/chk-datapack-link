# 채팅 블록 소환 지원 블록 목록 (BLOCKS.md)

> 치지직 시청자가 `!블록소환 [블록이름]` 명령어로 소환할 수 있는 마인크래프트 전체 블록 목록입니다.

## 명령어 사용법

- **형식**: `!블록소환 [블록이름]`
- **입력 예시**: `!블록소환 모래`, `!블록소환 참나무반블록`, `!블록소환 oak_slab`, `!블록소환 TNT`
- **검색 팁**: 브라우저나 모바일에서 **`Ctrl + F`** 키를 눌러 원하는 블록 이름을 바로 검색해 보세요!
